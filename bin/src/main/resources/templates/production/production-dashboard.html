Effectiveness Logic

OOE
Overall Operations Effectiveness
Logic:
OOE = Performance x Quality x Availability
Where Availability = Actual Production Time / Operating Time
OEE
Overall Equipment Effectiveness
Logic:
OEE = Performance x Quality x Availability
Where Availability = Actual Production Time / Schedule Time
TEEP
Total Effective Equipment Performance
Logic:
OOE = Performance x Quality x Availability
Where Availability = Actual Production Time / All Time
CAPACITY UTILIZATION
Logic:
CAPACITY UTILIZATION = Planned Operating Time / Total Time
